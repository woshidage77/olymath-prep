# 一朵教学｜题库来源与引入边界

更新：2026-09-16。本仓库代码采用 MIT；第三方题目继续遵守各自的数据许可，不能把代码许可证当成题目版权授权。

## 已纳入公开 Demo 的题目

当前五年级题库共 136 道：

- 8 道“观察物体（三）”原创互动题，来源状态为“原创待教师审核”。
- 28 道覆盖其他人教版五年级单元的原创专题种子题，来源状态为“原创待教师审核”。
- 100 道 CMATH 五年级中文应用题。原始数据集采用 CC BY 4.0，本项目保留原题干与标准答案，增加单元归类和教学标签。

CMATH 的作者、原始链接、许可和本项目变更记录见 [`backend/data/README.md`](../backend/data/README.md)。这些题目的单元归类由启发式规则生成，尚未经过教师逐题复核；数据集只提供标准答案，不能冒充分步讲解已经核验。

## 已核查的历届竞赛入口

以下页面适合作为教师找题和后续来源登记入口：

- [Math Kangaroo USA 历年试卷](https://mathkangaroo.org/mks/practice/pdf-exams/)：提供 Grades 5–6 等不同组别的历年原卷，可查看或打印。
- [Australian Mathematics Competition](https://amt.edu.au/amc)：官方说明 Upper Primary 面向五、六年级，并公开少量历届样题与解答。
- [Raffles Mathematical Olympiad](https://www.ri.edu.sg/rmo/)：官方页面提供部分历年题目与解答下载。
- [全港小学数学挑战赛](https://hkpmc.cswcss.edu.hk/)：官方网站提供比赛题目及答案入口。
- [Hong Kong Mathematics Olympiad](https://www.edb.gov.hk/en/curriculum-development/kla/ma/res/sa/hkmo-index.html)：香港教育局页面提供历年试卷索引，但主要面向中学，不直接归入五年级题库。

这些网站允许在线查阅或下载，不等于允许本项目批量复制、翻译并以 MIT 再分发。没有找到明确的再分发许可时，系统只保存赛事、年份、组别、题号、官方链接和教师私有笔记；不把完整题干和图片提交到公开仓库。

因此，“把历届题都录入”要拆成两层：公开仓库只纳入原创或许可明确的数据；教师个人工作区可以保存本人有权使用的试卷和拍照题，但默认私有，不进入公开种子库。

## 课程目录依据

五年级文件夹采用人教版上下册单元框架。目录交叉核对了国家中小学智慧教育平台公开的[五年级上册教材目录](https://v2.ykt.cbern.com.cn/65/document/eb62107828524d268c3dccacd3ee8d7b/pdf.pdf)与教育部基础教育精品课章节名单。目录名称仅用于课程导航，没有复制教材正文、例题或插图。

## 后续导入要求

每个外部来源至少记录：来源名称、官方链接、取得日期、版本或年份、组别、题号、许可证据、署名要求和允许用途。每道题保存稳定 ID、原始来源、修订关系、答案审核、数学审核和教学标签。

来源不清的题目不能进入公开种子库。教师照片和购买的试卷默认私有；OCR、搜索索引、日志、导出文件和模型调用都必须遵守同一可见范围。
