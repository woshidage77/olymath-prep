# A3｜RAG 检索基线实现说明

更新：2026-09-16。状态：题库检索、上下文构造和 LangGraph 接入已完成本机工程回归；语义 embedding、真实生成模型、教师检索评价和开发者本人理解尚未验收。

## 本阶段交付了什么

当前实现是可替换的 2-Step RAG 检索基线：先取得起始题，再检索相关题并形成可追溯上下文，最后由确定性 Mock 节点整理备课草稿。它具备 RAG 的知识库、检索器和上下文构造部分；因为尚未调用生成模型，不能称为已经验证完整的生成式 RAG 效果。

```mermaid
flowchart LR
  Q[教师检索词/选中题] --> K[五年级 136 道题知识库]
  K --> D[LangChain Document + metadata]
  Q --> R[关键词与标签检索器]
  D --> R
  R --> C[带 problem_id / revision_id / source 的上下文]
  C --> G[LangGraph Mock 草稿节点]
  G --> V[引用与结构校验]
  V --> H[等待教师确认]
```

## 题库结构

题库现有 136 道：8 道原创组合体观察题、28 道覆盖其他单元的原创专题题和 100 道 CC BY 4.0 的 CMATH 五年级题。每题保存稳定题目 ID、修订 ID、题干、答案、学段、年级、册别、单元、概念、方法、标签与来源状态。空间题额外保存几何坐标。原创题仍标记为“原创待教师审核”，CMATH 题标记为“待教师分级”；工程测试通过不代表教学内容已经获教师确认。

课程入口按人教版五年级上下册的 15 个单元组织成文件夹。CMATH 的单元归类由启发式规则生成，来源和变更说明见[题库来源文档](QUESTION_SOURCES.md)。

[retrieval.py](../backend/app/retrieval.py) 将完整题目转成 LangChain `Document`。一题对应一个文档，不机械拆开题干和答案；`metadata` 保留检索、过滤和引用所需字段。当前数据规模小且已经是结构化知识库，无须先增加 PDF loader 或向量数据库。

## 检索契约

`POST /api/demo/problems/search` 接收查询、年级和条数限制。当前检索器执行：

1. 按年级和可选专题过滤。
2. 对标题、题干、问题、概念、方法、标签和专题做中文双字片段/英文词匹配。
3. 使用集中定义的字段权重排序；返回命中的字段和整数分数。
4. 分数只是确定性排序依据，不是相关性概率或教学质量置信度。
5. 没有结果返回空列表；输入空白由请求校验返回 422；服务异常不会伪装成空结果。

示例查询“上视图 高度”会优先召回“反例题：上视图能看出高度吗”。回归测试固定了这个期望，用于发现索引或权重变化造成的召回退化。

## LangGraph 中怎样使用

[workflow.py](../backend/app/workflow.py) 在精确取得起始题后执行 `retrieve_context`：

- 教师提供 `search_query` 时使用原查询；否则根据选中题的专题、概念和方法生成确定性查询。
- 排除起始题本身，召回最多 3 个候选。
- 上下文始终包含选中题，再追加候选；每项保存 `problem_id`、`revision_id`、来源和完整摘录。
- 显式教学链关系排在前面，其他结果以“同专题候选”加入，并说明共同训练的概念或方法。
- API 仍返回检索策略、查询、候选和上下文，供调试和后续评测；教师页面不展示 RAG、工作流节点、匹配字段或分数。

## 为什么现在没有 embedding

当前先验证中文关键词/标签基线与题目数据契约。真实 embedding 会引入模型选择、版本、维度、外发范围、费用或本地资源占用，也需要固定查询集比较增益。根据“基本功能完成后再统一测模型”的开发顺序，本阶段不使用 Fake Embedding、随机向量或未评测模型制造语义检索已完成的假象。

后续接入时保持 `search(request)` 输出契约不变，使用同一查询集比较关键词基线与语义/混合检索的 Recall@K、教师认可率、延迟和成本。收益不足时保留关键词基线。

## 已验证与尚未验证

已覆盖：15 个单元目录与题数一致性、专题过滤、可解释排序、无结果、空查询、年级过滤、上下文修订引用、显式查询进入图状态、136 道题 ID/元数据唯一性，以及空间题的方块数与投影不变量。

尚未覆盖：逐题数学与单元归类审核、同义词/自然语言语义召回、embedding、向量索引重建、数据库权限隔离、竞赛试卷授权导入、教师检索评价、生成回答的 groundedness。当前内存题库只适合开发原型。
