# A4｜基本功能补齐说明

更新：2026-09-16。此阶段交付的是本地单用户 MVP，用来验证完整备课操作，不代表多人生产系统、OCR 或模型教学质量已经验收。

## 可运行闭环

1. 教师从题库选择一道题；配置模型时，Graph 增加“题目分析”节点，读取题干、问题、参考答案和已有标签，产出经 Pydantic 校验的知识点、题型、难点、易错点、追问与变式。
2. LangGraph 把模型分析与检索候选一起整理为“原题 → 概念与方法 → 回到原题”的结构化备课资料。没有密钥时沿用确定性基础方案；页面明确显示当前模式。
3. 教师可以围绕当前题继续问答。每次请求只携带当前题和最多 12 条页面内对话，不把密钥或响应写进开源仓库；调用设置 `store=false`。
4. 备课方案可保存到本机 SQLite，继续编辑标题、备注、题目顺序、题间作用、课堂追问和讲解动作。编辑会把状态恢复为待确认，版本号避免旧页面覆盖新改动。
5. 草稿可确认、删除，并分别导出包含答案与教学备注的教师版，以及不含答案的学生版 Markdown。
6. 单题照片经过真实类型、安全解码、像素/体积限制、EXIF 方向修正和重新编码后，保存到本机私有目录。当前要求老师人工校对题目文字，再调用现有题库检索。

## 数据与安全边界

- 默认私有目录是仓库下被 `.gitignore` 排除的 `private_data/`，也可以用 `YIDUO_PRIVATE_DIR` 指向仓库外目录。
- 上传文件名由服务端生成，路径通过 `Path.resolve()` 与 `relative_to()` 校验；上传目录没有静态公开路由。
- 图片统一重新编码为 PNG，去除原始元数据；删除记录时同时删除文件。
- 草稿引用题目修订 ID。题目修订变化时拒绝无提示覆盖，要求重新打开并核对。
- OpenAI 密钥只从后端环境变量读取。没有密钥时 AI 接口返回 503，普通备课不会伪装成模型结果。

## 当前技术选择与后继

SQLite 适合本地单用户 Demo，可以证明重启后数据仍在并覆盖编辑、审核、导出和删除。它不承担多人权限与远程并发；进入真实试用前应迁移到 PostgreSQL，加入用户、组织、资源归属与对象权限。当前“拍照录题”只完成安全上传、人工校对和检索，不得称为 OCR。模型只完成适配器与结构化输出连通回归，真实正确性、延迟、费用和教学效果仍在 A6 统一评测。

模型接口采用 OpenAI Responses API；结构化分析由 SDK 的 Pydantic 解析能力校验，多轮问答在客户端提交受限历史。官方接口支持文本/图片输入、结构化 JSON、`previous_response_id` 以及 `store` 设置；本项目为了减少服务端保留和简化本地数据边界，当前显式使用 `store=false` 并手工传递短历史。参考：[Create a model response](https://developers.openai.com/api/reference/cli/resources/responses/methods/create)。
