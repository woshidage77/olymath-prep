# 首页重设计 · 2026-09-17

目标：把单张卡片式入口改为全宽、连续、有真实操作入口的教师产品首页。

参考：
- https://github.com/leoMirandaa/shadcn-landing-page （核查时约 2,000 stars）：导航、功能说明、FAQ、页脚的完整站点结构。
- https://github.com/shadcn-ui/ui ：一致的组件状态、键盘焦点与克制的界面层级。
- https://www.magicschool.ai/magicschool ：以教师任务组织产品能力与入口。

本次为原创 Vue/CSS 实现，仅参考信息结构；没有复制第三方源码、品牌、图片或用户评价。

实现：
- 首页脱离工作台 max-width 容器，背景铺满宽度，桌面首屏随视口高度展开。
- 左侧明确产品主张与主操作，右侧可切换方程、植树、面积三个教学场景示例。
- 示例明确标注为教学场景，不能当成实时模型生成结果。
- 连续的备课方式、专题入口、FAQ 和页脚；专题直达对应单元，功能入口直达草稿和照片录题。
- scoped CSS、移动端单列布局、焦点样式、减少动效偏好；未新增运行时依赖。

验证：
- npm run build：Vue 类型检查与 Vite 构建通过。
- 浏览器核验 1440×900 和 390×844，均无横向溢出。
- 例题切换显示对应公式，首页直达简易方程、草稿和照片录题成功。
- 本地后端未运行导致的 HTTP 500 已通过恢复服务解决。
- 本轮仅修改前端与说明文档，没有改变后端业务逻辑。
